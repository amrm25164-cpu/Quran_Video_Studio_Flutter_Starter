# Quran Video Studio — Flutter Starter

This is a Flutter starter project for Klencod IDE.

## Import
1. Import this ZIP as a project if Klencod supports Flutter project ZIP imports.
2. Otherwise create a new Flutter project named `quran_video_studio`.
3. Replace `lib/main.dart` with the provided `lib/main.dart`.
4. Replace `pubspec.yaml` with the provided `pubspec.yaml`.
5. Run `flutter pub get` if a dependency-install action is available.
6. Run/Preview the app.

## Current features
- Arabic right-to-left studio interface
- Editable verse and surah label
- Preview aspect ratio: portrait, landscape, square
- Text size, color and opacity controls
- Background dimming control
- Reciter name dropdown (names only; no recitation files are bundled)

## Not implemented yet
- Trusted full Quran text source
- Online recitation streaming
- Audio/video file picker
- Accurate verse timestamps / automatic sync
- Real MP4 video rendering/export
- Project import/export

Buttons for features not yet implemented show an explanatory message instead of pretending to work.
